WINDOWS SETUP

1. Extract the entire game ZIP to a folder on your computer.
2. Install Python 3.10 or newer if needed: https://www.python.org/downloads/windows/
3. Double-click Setup.cmd and choose your ORIGINAL PS3 disc ISO.
4. Wait for READY. Setup prepares data in PSP/GAME/PVZPSP automatically.
5. Copy PVZPSP into PSP/GAME on your PSP memory card and start it from Game.

Use the PS3 BLUS30852 version 01.00 disc containing NPUA_30059.
An existing PSP Plants vs. Zombies ISO is not the required source.
Setup offers to install missing Pillow/FFmpeg tools. It does not download game assets.

Back up saves before updating. Existing data is kept until preparation succeeds;
replaced data is backed up. Do not close setup while it is preparing files.

If setup fails, the error is shown in its window and details are in setup.log.
Manual setup and developer instructions: docs/MANUAL-SETUP.txt and docs/DEVELOPMENT.md.
