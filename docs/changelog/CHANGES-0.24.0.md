# 0.24.0 — Gameplay polish development checkpoint

- Continuous Imp flight/landing, separate dancer transitions, rising backups,
  correctly scaled dancers and independent backup groups.
- Corrected repeat/Survival/Last Stand budgets, mode-specific waves, shield-health
  pacing, delayed final arrivals and normal armored pool zombies.
- Zomboss idle recovery, attack sequencing, Bungee exit, source-driven ball motion
  and removal of the erroneous instant loss from an offscreen boss ball.
- Fixed homing target identity, portal jump continuity, Bobsled leader reuse and
  Zombotany square cleanup. Basic Heavy Weapon shots use pea artwork.
- Gradual reward pickups with matching endpoints/sounds and complete transition
  gating. Dave starts speaking after entering and finishes his original grab.
- New prepared-data recipe and version 14 game saves; version 5 profiles retained.

This does not finish every original combat, camera, effect or special-mode detail.

[validation](../reference/VALIDATION-0.24-DEVELOPMENT.md).
