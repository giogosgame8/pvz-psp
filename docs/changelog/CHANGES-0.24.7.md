# PvZ PSP 0.24.7

- Fixed duplicate Digger emergence sounds and sound cues carried over when a
  zombie slot is reused.
- Reduced repeated work in gameplay audio and board rendering.
- Improved checkpoint validation and first-launch save migration.
- Press **Select** during a level to collect frame timings. Press it again to
  write the summary to `PSP/GAME/PVZPSP/runtime.log`.

Windows setup still uses your original PS3 ISO and supports reusing verified
0.24.6 game data. Keep your saves in `PSP/SAVEDATA/PVZPSP`.
