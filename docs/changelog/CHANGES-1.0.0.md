# PvZ PSP 1.0 full release

- Play the 50-stage Adventure, Mini-games, Puzzle, Survival, Zen Garden, and the
  ending in the offline single-player release.
- Includes the 0.24.7 gameplay audio, board rendering, and checkpoint fixes.
- Press **Select** during play to collect frame timings. Press it again to
  write the summary to `PSP/GAME/PVZPSP/runtime.log`.

Windows Setup can verify and reuse existing 0.24.6 or 0.24.7 game data. Saves
live in `PSP/SAVEDATA/PVZPSP`.
